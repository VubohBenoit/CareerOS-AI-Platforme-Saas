# CareerOS AI — Personas et parcours utilisateur

## Persona 1 : Léa Moreau — Développeuse en transition

### Profil démographique
- **Nom** : Léa Moreau
- **Âge** : 28 ans
- **Localisation** : Paris, France (open to remote + EU)
- **Statut** : CDI en fintech depuis 4 ans, démission volontaire
- **Formation** : Diplôme d'ingénieur informatique (ECE Paris)

### Contexte professionnel
- **Expérience** :
  - 4 ans backend Python/Django (fintech)
  - 2 ans DevOps (Docker, Kubernetes, CI/CD)
  - Plusieurs projets Open Source (GitHub 300 stars)
  - Quelques talks en conférences (Python Paris)
- **Compétences** :
  - Technique : Python, FastAPI, Django, PostgreSQL, Docker, Kubernetes, Redis, Git
  - Soft skills : Gestion de projet, mentorat junior, communication écrite
  - Langues : Français (natif), Anglais (courant), Espagnol (basique)

### Motivations et objectifs
**Pourquoi elle change** :
- Fintech = secteur saturé, burnout ambiance
- Envie d'impact : faire du machine learning, de l'impact sociétal
- Défi intellectuel : approfondir ML, architecture cloud

**Objectif à court terme** (6 semaines) :
- Décrocher 1 offre Sr. Backend ou ML Engineer dans une deeptech/healthtech
- Salaire : 45-55k€ minimum (stable)
- Contrat : CDI 100% remote ou Paris

**Critères pour accepter** :
- Stack tech moderne (Python, cloud, infrastructure agile)
- Équipe < 20 ingénieurs (pas de grosse boîte impersonnelle)
- Mission claire (pas de politiques internes)
- Grow tech + leadership path

### Douleurs actuelles
1. **Volume** : Trop d'offres non-pertinentes sur LinkedIn (PME débiles)
2. **ATS** : Ses 4 ans en fintech ne matchent pas = peu de réponses
3. **Temps** : Adapter CV + lettre pour chaque candidature = 30 min/offre
4. **Confiance** : Passer de fintech à deeptech = imposter syndrome à l'entretien
5. **Suivi** : Après envoi = qui réagit ? quand relancer ?

### Comportement d'utilisation
**Fréquence** :
- Visite platform : 5-6j/semaine (matin 30 min + midi 30 min)
- Candidature : 3-5 offres/jour (75-100/mois)
- Relances : 1x/semaine

**Devices** :
- Primaire : MacBook Pro 16" (travail)
- Secondaire : iPhone (notifications)
- Pas d'utilisation tablette

**Compétence tech** :
- Senior (confortable avec APIs, outils dev)
- Veut des features avancées (webhooks, intégration GitHub)

### Profil démographique

- **Âge** : 42 ans
- **Localisation** : Lyon, France (open to Paris + remote)
- **Statut** : Licenciement économique après 15 ans en conseil
- **Formation** : HEC Paris, MBA Stanford

### Contexte professionnel
- **Expérience** :
  - 15 ans en conseil en stratégie (3 années Deloitte, 12 ans cabinet boutique)
  - 8 ans management (team lead → head of practice = 20 personnes)
  - Expertise : transformation digitale, stratégie cloud, M&A tech
  - 2 startup projects (advisory role)
- **Compétences** :
  - Stratégie, P&L, gestion RH, négociation, présentation executive
  - Pas de coding mais connaît bien tech (travaillé avec CTO/dev teams)
  - Langues : Français, Anglais (business), Allemand (parlé)

### Motivations et objectifs
**Pourquoi il change** :
- Conseil = pas stable (restructuring permanent)
- Veut du concret : inside une boîte, pas de client hopping
- Envie : Co-founder ou VP/Head of Strategy dans une scale-up

**Objectif à court terme** (3-4 mois) :
- CPO, VP Product, Head of Strategy dans une tech scale-up
- Salaire : 80-120k€ (equity possible)
- Contrat : CDI, engagement long-terme possible
- Localisation : Paris preferred, remote OK

**Critères pour accepter** :

1. **Repositionnement** : Consultant ≠ product person, comment l'expliquer ?

5. **Culture fit** : Peut pas juste regarder mission, faut assurer culture match

- Visite platform : 3-4j/semaine (session 1-2h)
- Recherche : Ultra-ciblée (max 20 offres/mois)
- Candidature : 1-2 offres/mois seulement (qualité)
- Relances : strategic (si entreprise strategique, relance agg)

**Devices** :
- Primaire : iPad + keyboard (prefer tablet, mobilité)
- Secondaire : iPhone
- Work : PC (mais pas utilisé pour cette recherche)

**Compétence tech** :
- Moyenne (know tools, not deep tech)
- Veut simplicité, pas de paramétrages complexes

## Summary

Ces 3 personas couvrent le spectre complet du marché job search :
1. **Léa** = développeurs mid-level en transition (tech-focused, volume, speed)
2. **Marc** = cadres senior/leaders (quality, strategy, exec coaching)
3. **Aminata** = fresh grads/juniors (volume, confidence, feedback)

Chaque persona a des besoins distincts, et CareerOS doit supporter tous les 3.

**Next step** : Valider ces personas avec target users, puis passer à l'architecture technique.
