## Decision Framework

For each feature request, we evaluate:

1. **Impact** (1-10): How much will this help users?
2. **Effort** (1-10): How hard is it to build?
3. **Priority Score** = Impact / Effort
4. **Strategic Fit**: Does this fit our vision?
5. **User Demand**: Are users asking for this?

**Build only if: Score > 1.0 AND Strategic Fit > 0.7**
